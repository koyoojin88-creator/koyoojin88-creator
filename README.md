## 재보고 되돌린 것

숫자가 결정을 뒤집은 기록을 [실측](https://koyoojin.pages.dev/measured) 탭에 모아 둡니다.

- **모델이 아니라 기준을 고쳤다** — 기준값의 궤적을 그려 보니 4년이 지나도 수렴하지 않는 누적 평균이었다. Little's law로 기준을 다시 잡자 오차가 +3.0% → **+0.5%**. 모델은 한 줄도 안 고쳤다 · [글](https://koyoojin.pages.dev/posts/a-ruler-still-growing)
- **12배 싼 모델로 갈아탄 결정을 되돌렸다** — 성조만 다른 최소대립쌍 10쌍을 실제 채점 경로에 넣었더니 탐지 **0/10**
- **목록의 수를 늘리는 대신 줄였다** — 악장 번호를 전수 조사하니 다른 곡에 걸려 있던 것들이 나왔다. 맞는 수가 큰 수보다 낫다
